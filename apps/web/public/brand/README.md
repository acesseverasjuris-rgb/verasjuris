# Ativos oficiais da marca

Coloque aqui apenas arquivos mestres autorizados do VerasJuris:

- `logo-positive.svg` — símbolo e “Veras” em azul-marinho, “Juris” em azul elétrico, fundo transparente
- `logo-negative.svg` — assinatura branca sobre transparente, para uso sobre azul-marinho
- `symbol.svg` — símbolo isolado, somente para favicon, avatar e espaços muito reduzidos

Enquanto esses arquivos não estiverem nesta pasta, a interface usa o nome VerasJuris em texto, em uma única cor. Isso não é a assinatura oficial e não deve ser tratado como logotipo.

Não redesenhe o símbolo, não recomponha o lettering e não altere cores, proporção, sombra, gradiente ou rotação.
