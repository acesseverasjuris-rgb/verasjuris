# Empresarial (Etapas 11–13)

## Princípio

Módulo `CORPORATE` — operações societárias ligadas ao matter.

Schema: `corporate_cases` (`caseKind`, metadata). API: `…/corporate-cases`. Features: `corporate_case`, `corporate_transaction`.

Contratos societários operacionais usam também domínio **Contratos** (`docs/CONTRACTS.md`) — distinto de minuta jurídica (`LegalDraft`).
