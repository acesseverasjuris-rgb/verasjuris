# Extrajudicial (Etapa 19)

Orquestração de cartórios/serviços. Cartório `manual` → `unverified`. Orçamentos `manual_estimate` com disclaimer. `fee_table`/`provider` só com integração configurada. Protocolo automático via `RegistryProvider`; manual exige evidência documental.

API: `/v1/organizations/:orgId/extrajudicial/*`. Portal: `/portal/servicos-extrajudiciais`.

Emolumentos/fees estimados ≠ ledger de plataforma. Cobrança SaaS/repasse (allocation ≠ PSP split): `docs/FINANCE.md`, `docs/SPLIT.md`, `docs/PLATFORM_FEES.md`, `docs/PAYMENT_PROVIDER.md`.
