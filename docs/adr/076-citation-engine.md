# ADR 076 — CitationEngine

## Status

Aceito (Etapa 7.1).

## Decisão

- Formatação e validação de citações concentram-se no **`CitationEngine`** (`@verasjuris/ai`).
- Status: `unverified`, `source_available`, `verified`, `source_unavailable`, `invalid`, `stale`.
- O motor **nunca** promove sozinho a `verified`.
- Inserção em minutas permanece não implementada (stub explícito).
