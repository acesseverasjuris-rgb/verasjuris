# ADR 077 — Jurisprudência não verificável não se cita como real

## Status

Aceito (Etapa 7 / 7.1).

## Decisão

- Sem registro no catálogo / sem URL https / sem metadados mínimos → **não** apresentar como julgado real.
- Status `invalid` ou empty state; ResearchGateway sem provider não inventa resultados.
- IA de análise/revisão proibida de fabricar ementas ou números de processo.

## Motivo

Anti-alucinação jurídica como regra de produto, não só de prompt.
