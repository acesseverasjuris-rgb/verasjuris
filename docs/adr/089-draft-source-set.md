# ADR 089 — Draft source set versionado

## Status

Aceito (Prompt 15).

## Decisão

- Fontes da minuta ficam em `legal_draft_source_sets` / itens tipados.
- Assistência IA só cita IDs já presentes no set.
- Conjunto não é reescrito silenciosamente após uso material na geração.

## Motivo

Proveniência auditável e alinhamento anti-alucinação (ADRs 075–077).
