# ADR 149 — Divulgação de documentos no Marketplace

## Status

Accepted

## Context

Candidatos não devem receber documentos sensíveis antes da contratação.

## Decision

- Antes do aceite: preview/metadata mínimos + ACL restritiva.
- Após aceite/engagement: liberação conforme policy.
- Documentos de verificação profissional: nunca públicos.

## Consequences

Safe preview + Document ACL; testes de leak obrigatórios.
