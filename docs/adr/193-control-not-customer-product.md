# ADR 193 — Control ≠ customer product

## Status

Accepted

## Context

Risco de tratar telas internas como features vendáveis a escritórios.

## Decision

Control é domínio interno. Monetização/planos não embalam Control como SKU de cliente final sem decisão explícita.

## Consequences

Copy e docs deixam explícito; analytics de produto cliente vive em abas separadas.
