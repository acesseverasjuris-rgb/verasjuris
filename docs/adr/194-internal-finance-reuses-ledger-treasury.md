# ADR 194 — Internal finance reuses Ledger/Treasury

## Status

Accepted

## Context

Orçamento interno não deve criar segundo livro-caixa.

## Decision

Budgets/cost centers/expense reports em Control; cash actual e postagens via Ledger/Treasury existentes.

## Consequences

UI Control aponta tesouraria; ADR 184 (actual≠forecast) permanece.
